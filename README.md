# Tribute Website

## Project Overview
This project is a Tribute Website created using HTML and CSS to honor and present information about an inspirational personality.  
The website focuses on semantic structure, clean layout, and responsive design principles.

## Features
- Simple and clean UI using pure HTML and CSS
- Well-structured content layout
- Responsive design for different screen sizes
- Beginner-friendly and easy to understand code
- Organized sections for biography, achievements, and highlights

## Technologies Used
- HTML5 – for semantic structure
- CSS3 – for styling and layout
